### 2.3 MES 报工（MesService）

- 地址：`POST http://192.168.4.104:9291/api/mes/jobBooking/create`，`Content-Type: application/json;charset=UTF-8`
- 代码：`04.Model\Bots.TestBench.Model.Task\Service\MesService.cs`、`Bots.TestBench.CTS\Services\MesService.cs`
- **作用**：工序完成后向 MES 上报"报工"结果（工序代码 + 设备SN + 合格状态 + 过程时长），用于 MES 生产工序追溯与工时统计。
- **使用产品（阶段）**：老化（`AgingItem.cs` 老化完成、T05 老化脚本）、出厂检验（`TestTaskRunViewModel.cs` 通用出厂检验完成）、P21（各套件模块工序，7 个任务脚本）、CTS（整机任务）。
- **可替换说明**：不可替换（独立工序报工流程，无等价接口）。

**请求体**：
```json
{ "ProcedureCode": 101, "DeviceSet": [ { "Sn": "660U22D010001", "Status": 1, "TimeSpan": 2 } ] }
```
> `ProcedureCode` 工序代码；`Status`：1 合格 / 2 不合格；`TimeSpan` 过程时长（小时）

**返回体**：
```json
{ "IsSuccess": true, "Code": 0, "Msg": "", "Data": [ { "Sn": "...", "IsSuccess": true, "Reason": "" } ] }
```

**返回字段使用情况**：`IsSuccess`（整体是否成功，`MesService.Send` 直接返回）、`Data[].Reason` / `Msg`（失败原因，用于界面提示）✅ 在用；`Code`、`Data[].Sn` 解析但未被读取 ⚑（保留作接口契约字段）。
